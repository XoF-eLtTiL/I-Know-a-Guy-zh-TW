# I Know a Guy XUnity Assistant

`IKAG.LiveTranslationPatcher` is a BepInEx IL2CPP helper for the Traditional Chinese localization of **I Know a Guy: Shady Life Simulator**.

## Translation files

- `MainTable_Fixed_zh-TW.txt`: reviewed fixed translations.
- `MainTable_Regex_zh-TW.txt`: bounded dynamic translations.
- Machine-generated entries are reviewed before being merged; names, input keys, Pizza and dark-web product names remain unchanged where required.

Translations are loaded from:

`BepInEx/Translation/zh-TW/Text/`

## Update manifest

The default manifest is:

`https://raw.githubusercontent.com/XoF-eLtTiL/I-Know-a-Guy-zh-TW/main/manifest.json`

This repository publishes the translation files and their checksums. Patcher and updater source code are not published here.
