# I Know a Guy 繁體中文翻譯

此儲存庫只存放 **I Know a Guy: Shady Life Simulator** 的繁體中文翻譯資料，供中文化套件與自動更新功能使用。

## 檔案

- `Translations/MainTable_Fixed_zh-TW.txt`：固定翻譯
- `Translations/MainTable_Regex_zh-TW.txt`：動態 Regex 翻譯
- `Translations/_AutoGeneratedTranslations.txt`：保持空白，避免線上機翻
- `manifest.json`：檔案版本、大小、SHA-256 與下載位置

Patcher 原始碼、編譯 DLL 與 Logo 不在此儲存庫公開。
