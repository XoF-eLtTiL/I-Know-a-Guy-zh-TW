# I Know a Guy: Shady Life Simulator

《I Know a Guy: Shady Life Simulator》繁體中文化（台灣用語）。

## 翻譯檔案

- `MainTable_Fixed_zh-TW.txt`：人工校對的一般翻譯。
- `MainTable_Regex_zh-TW.txt`：限定範圍的動態文字規則。
- 人物名稱、鍵盤／滑鼠按鍵、Pizza 與指定暗網商品名稱依規則保留英文。
- 機器翻譯內容必須經過校對後才會合併。

翻譯檔載入位置：

`BepInEx/Translation/zh-TW/Text/`

## 安裝

1. 從 [Releases](https://github.com/XoF-eLtTiL/I-Know-a-Guy-zh-TW/releases) 下載最新完整安裝包。
2. 解壓縮後，將壓縮包內的所有檔案放到遊戲根目錄。
3. 從 Steam 啟動遊戲。

首次啟動可能需要稍等一段時間。

## 自動更新

`manifest.json` 提供翻譯檔與 Patcher 的版本、檔案大小及 SHA-256。Updater 只會安裝通過 HTTPS、大小與雜湊驗證的更新；本機自行修改的翻譯檔不會被覆蓋。
